Key Concepts (Short Notes)
Artificial Intelligence (AI): Machines ko human-like intelligence dena. Example: Siri, Alexa, ChatGPT.
Machine Learning (ML): AI ka subset jahan machine data se seekhti hai without explicit programming.
Example: Spam filter, Netflix recommendations.
Deep Learning (DL): ML ka advanced form jo Neural Networks use karta hai. Example: Face recognition,
Image generation (DALL·E, Midjourney).

# 4. Simple Calculator
def calculator(a, b, operation):
 if operation == "+":
 return a + b
 elif operation == "-":
 return a - b
 elif operation == "*":
 return a * b
 elif operation == "/":
 return a / b if b != 0 else "Error: Division by zero"
 else:
 return "Invalid operation"
print(calculator(10, 5, "+")) # 15
print(calculator(10, 5, "*")) # 50
